# ⚡ PCIe 6.0 学习系统

一个为 PCIe 6.0 验证工程师定制的纯本地学习系统：**知识库 + 测验 + 错题集 + 12 周学习计划 + 日历提醒**。

零依赖、无需安装、无需账号，数据保存在设备浏览器本地。

## 内容结构（双大模块：PCIe + RDMA）

**PCIe 6.0 组（M1~M13）**

| 模块 | 内容 |
|---|---|
| M1 | PCIe 基础回顾（分层/TLP 逐字段/流控记账/LTSSM 全子状态/配置空间地图/排序） |
| M2 | PCIe 6.0 总览（速率演进、四大支柱、逐层对比、互操作） |
| M3 | FLIT 机制（结构、六种类型、打包边界、装配算法） |
| M4 | PAM4 信令（四电平、格雷码、预编码、BER 预算） |
| M5 | FEC 与错误处理（RS 数学基础、双 CRC、First Retry） |
| M6 | 电源管理（L0p 过程细节、ASPM/L1 子状态） |
| M7 | 流控变化（FLIT 粒度、共享池记账演练） |
| M8 | 均衡与链路训练（preset/coefficient、PAM4 均衡、Loopback） |
| M9 | UIO 与 6.1 新特性（TLP 前缀/PASID、UIO 语义） |
| M10 | **验证重难点专题**（错误注入矩阵、参考模型、SVA 库、覆盖率、formal、Bug Top10） |
| M11 | 参考资料索引（规范章节地图与精读路线） |
| M12 | **VIP 与验证实战**（VIP 生态、bring-up、注错矩阵构建、集成经验、常见坑） |
| M13 | **样片定位案例**（debug 方法论 + 8 个典型失败模式教学案例） |

**RDMA / RoCEv2 组（R1~R9）**

| 模块 | 内容 |
|---|---|
| R1 | 体系结构（IB/RoCEv2/iWARP、verbs 对象、MR/rkey、Doorbell、CQ） |
| R2 | QP 状态机与传输类型（RC/UC/UD/XRC、状态迁移、RTR/RTS 属性表、操作全集） |
| R3 | RoCEv2 报文格式（封装逐层、BTH/DETH/RETH/AETH 逐字段、Opcode 表、GRH、ICRC） |
| R4 | 可靠传输与错误处理（PSN/ACK、Go-Back-N、RNR、完成状态码全集、ICRC 体系） |
| R5 | 无损网络与拥塞控制（PFC、死锁与 headroom、ECN/CNP、DCQCN、ETS） |
| R6 | 应用场景（AI 训练/GPUDirect、NVMe-oF、MPI、云虚拟化、IB 拓扑） |
| R7 | **RDMA 验证专题**（三方对账环境、流量模型、注错矩阵、状态机覆盖、性能、合规） |
| R8 | **VIP 与实战**（RoCE VIP 生态、SoftRoCE 黄金参考模型、PCIe 三通路协同、常见坑） |
| R9 | 资料与工具（IBTA 规范免费下载、rdma-core、perftest、SoftRoCE 实验环境） |

- **124 张知识卡片**（每张附 🎯 验证要点，规范级字段表/状态机/算法）
- **125 道题**（单选/多选/判断），每题带详细解析
- 12 周学习计划（任务打卡 + **自动顺延**：落后自动推后、提前完成提前开始）

## Windows 上使用

**方式一（最简单）**：直接双击 `index.html` 用浏览器打开。
单机使用完全够用，数据自动保存在浏览器里。

**方式二（推荐，手机可访问）**：双击 `start-server.bat`
- 需要电脑装有 Python（脚本会自动找 `py` / `python`）
- 启动后窗口会显示类似 `http://192.168.x.x:8000` 的地址
- **手机连同一个 WiFi，浏览器打开该地址即可使用**

> 防火墙首次会弹窗询问，勾选"允许访问专用网络"即可。

## 手机上使用（三种方式任选）

1. **公网访问（推荐）**：直接打开部署好的在线地址（见下节），任何设备、任何网络都能用
2. **局域网访问**：电脑运行 `start-server.bat`，手机同 WiFi 访问显示的地址。数据存在手机浏览器里。
3. **拷贝到手机**：把整个 `pcie6-study` 文件夹发到手机（USB/微信文件传输助手），用浏览器打开 `index.html`。

## 📖 规范原文关联（版权受控）

系统支持把**协议规范 PDF**（如 PCI Express Base 6.5，或免费的 IBTA InfiniBand 规范）的章节自动关联到每张知识卡片：

- **章节引用（公开）**：卡片下方「📖 规范关联」面板显示 §章节号 + 标题 + 页码（事实信息，可发布）
- **原文摘录（仅本地）**：在本机运行提取脚本后，可展开查看规范原文摘录

**生成方法**（在本机执行一次）：

```bash
python -m pip install pypdf
python tools/extract-spec.py "C:\path\to\NCB-PCI_Express_Base_6.5.pdf"
# 换其他规范（如 IB spec）：--spec-name "InfiniBand Architecture Spec Vol.1"
```

**版权/权限模型**：

- `js/data-spec.js`（原文摘录）已被 `.gitignore` 忽略，**永不提交、永不部署**——只存在于你的本机
- 仓库/公开站点只包含 `js/data-spec-refs.js`（章节号/标题/页码引用）
- 关联为关键词自动匹配，供定位精读使用；精确内容以规范原文为准

## 🌐 公网部署（GitHub Pages）

- **在线地址**：<https://damon-zxh.github.io/pcie6-study/>
- **仓库**：<https://github.com/damon-zxh/pcie6-study>

**手机安装为 App（PWA）**：

1. 手机浏览器（推荐 Chrome / Safari）打开在线地址
2. Android Chrome：菜单 → **添加到主屏幕**；iOS Safari：分享 → **添加到主屏幕**
3. 桌面出现应用图标，打开即全屏运行；首次加载后**支持离线使用**（Service Worker 缓存全部资源）

**内容更新流程**：

1. 修改本地文件（知识卡片 / 题目 / 计划等）
2. `git add -A && git commit -m "更新内容" && git push`
3. GitHub Pages 约 1 分钟后自动重新发布

> 注意：如果改动了 `index.html` / `css/` / `js/` 等被缓存的文件，记得同步把 `sw.js` 顶部的 `pcie6-study-v1` 版本号提升为 `v2`，否则老用户端可能继续用旧缓存（页面导航本身是网络优先，刷新一次即可拿到新 SW，随后自动清旧缓存）。

**数据说明**：学习进度存在各设备浏览器 localStorage 中——手机和电脑各自独立记录，跨设备用「设置 → 导出/导入 JSON」同步。

## 数据跨设备同步

学习记录保存在**每台设备自己的浏览器**里，换设备时：

1. 旧设备：**设置 → 📤 导出备份 JSON**
2. 新设备：**设置 → 📥 导入备份 JSON**

建议每周导出一次当备份。

## 每日提醒（手机系统级推送）

Web 页面本身无法后台推送，本系统用日历方案实现真提醒：

1. **计划页 → 📥 导出日历提醒 (.ics)**
2. 把 ics 文件发到手机（AirDrop/微信/网盘均可），打开并"添加到日历"
3. 之后**每天 21:00（提前 15 分钟）**手机会收到学习提醒，共 84 天（12 周）
4. Windows 上也可以直接双击 ics 导入系统日历

另外：打开应用时顶部横幅会显示当前周主题与任务进度（应用内提醒）。

## 功能速览

- **📚 知识库**：按模块浏览/搜索，标记已读，卡片附验证要点
- **📝 测验**：按模块/全库/错题出题，随机或顺序；50 题模拟考
- **❌ 错题集**：答错自动收录，**连续答对 2 次自动移出**，可随时重练
- **📅 计划**：12 周任务打卡，开始日期可设，当前周自动高亮
- **📊 统计**：已读覆盖、各模块正确率（红黄绿）、连续学习天数 🔥
- **🌗 深色模式**：右上角切换

## 自己扩充内容

- 加知识卡片：编辑 `js/data-knowledge.js`，往 `KNOWLEDGE` 数组里追加（格式照抄现有条目，body 支持 `**粗体**`、\`代码\`、`-` 列表、`|` 表格、\`\`\` 代码块）
- 加题目：编辑 `js/data-questions.js`，往 `QUESTIONS` 数组追加（`type`: single/multi/judge；multi 的 `answer` 是数组）
- 改计划：编辑 `js/data-plan.js`

改完刷新浏览器即可生效。
